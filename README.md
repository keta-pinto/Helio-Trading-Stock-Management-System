# Hélio Trading — Stock Management System

A static web-based stock management system developed for Hélio Trading, a store specializing in computer and IT equipment. The project provides an interface for managing and monitoring products, stock levels, and inventory information in an organized and practical way.

Project Status: This project is currently a static frontend implementation and is still under development. It does not currently include a backend, database integration, or real-time stock management.

# 🚀 Technologies
HTML5 <br>
CSS3 <br>
JavaScript

# 📋 Features
Product registration and management <br>
Stock quantity management <br>
Product inventory overview <br>
Product search and organization <br>
Interactive user interface <br>
Stock status visualization <br>
Clean and intuitive dashboard

# ▶️ Running the Project

Since this is a static website, no backend or server-side environment is required. Just clone or download the project. Then, open the index.html file.
